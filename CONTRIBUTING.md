# Contributing

1. Keep provider integrations optional and honest about configuration.
2. Never add unofficial WhatsApp automation, covert recording, credential leakage, or bulk outreach without approval controls.
3. Run `npm test` and `npm run build` before submitting changes.
4. Bug fixes must be narrowly scoped: reproduce, identify root cause, modify only affected code, run relevant and regression tests, and update `CHANGELOG.md`.
5. Do not silently overwrite knowledge or skill versions.
